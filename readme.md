# 📌 Desafio do Classificador de Nível para Heróis

Neste desafio, você terá de criar um Classificador de nível para Heróis utilizando JavaScript.

## 📌 O Que deve ser utilizado

- Variáveis
- Operadores
- Laços de repetição
- Estruturas de decisões

## 📌 Objetivo

Crie uma variável para armazenar o nome e a quantidade de experiência (XP) de um herói, depois utilize uma estrutura de decisão para apresentar alguma das mensagens abaixo:

Se XP for menor do que 1.000 = Ferro
Se XP for entre 1.001 e 2.000 = Bronze
Se XP for entre 2.001 e 5.000 = Prata
Se XP for entre 5.001 e 7.000 = Ouro
Se XP for entre 7.001 e 8.000 = Platina
Se XP for entre 8.001 e 9.000 = Ascendente
Se XP for entre 9.001 e 10.000= Imortal
Se XP for maior ou igual a 10.001 = Radiante

## 📌 Saída

Ao final da execução do código deve se exibir uma mensagem:
"O Herói de nome **{nome}** está no nível de **{nivel}**"

## 📌 Como Executar

1. Clone ou baixe este repositório em sua máquina:

   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```

2. Acesse a pasta do projeto:

   cd nome-do-projeto

3. Abra o arquivo index.html em um navegador de sua preferência
   (Chrome, Firefox, Edge, etc.).

4. O navegador exibirá automaticamente as janelas de entrada (prompt) para:
   - Nome do herói

   - Quantidade de XP

5. Após cada entrada, o resultado será exibido:

   Em uma janela de alerta (alert)

   No console do navegador (console.log)

6. Para encerrar a execução do programa, digite sair em qualquer uma das entradas.

💡 Para visualizar o console.log, pressione F12 e acesse a aba Console.
